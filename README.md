# Python_prc

Python入門書に掲載されているサンプルコードを、学習用にまとめたリポジトリです。

## 概要

書籍の内容を学びながら、サンプルコードを実際に動かしたり、書き換えて試したりするために使用します。アプリケーションやライブラリの配布を目的としたものではありません。

## 実行方法

Python 3 がインストールされた環境で、実行したい `.py` ファイルを選び、次のように実行してください。

```bash
python ファイル名.py
```

環境によっては `python3` コマンドを使用してください。

## 注意事項

- コードは学習用のサンプルです。書籍の説明や実行環境に応じて、内容が変更されることがあります。
- 書籍の名称や各サンプルの説明は、必要に応じて各ファイル内に記載してください。
